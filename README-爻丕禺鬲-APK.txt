هنرستان شهدا راه‌آهن — پروژه اندروید برای ساخت APK

این پوشه یک پروژه Android Studio است که رابط فارسی اپ را داخل WebView اجرا می‌کند.
امکانات: اطلاعیه‌ها، برنامه هفتگی، پروژه‌های دانش‌آموزی، تکالیف، پنل مدیریت نمایشی.

پیش‌نیازها:
- Android Studio جدید (پیشنهاد: نسخه پایدار)
- Android SDK Platform 35
- JDK سازگار با Android Gradle Plugin 8.7.x (معمولاً JDK 17)
- اینترنت برای دانلود اولیه وابستگی‌های Gradle

روش ساخت APK:
1. فایل ZIP را Extract کنید.
2. Android Studio را باز کنید و Open را بزنید.
3. پوشه ShohadaRailwayAndroid را انتخاب کنید.
4. منتظر بمانید Gradle Sync تمام شود. اگر SDK 35 نصب نیست، از SDK Manager نصبش کنید.
5. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
6. پس از پایان، از اعلان Build روی Locate بزنید.
   مسیر معمول APK:
   app/build/outputs/apk/debug/app-debug.apk
7. فایل APK را به گوشی منتقل کنید و نصب کنید. ممکن است لازم باشد اجازه نصب از این منبع را در تنظیمات اندروید فعال کنید.

ساخت نسخه امضاشده برای انتشار:
Build > Generate Signed Bundle / APK > APK را انتخاب کنید و یک keystore بسازید.
فایل keystore را محرمانه نگه دارید و از آن نسخه پشتیبان امن بگیرید.

پنل مدیریت:
- رمز نسخه نمایشی: 1234
- داده‌ها در حافظه محلی همان نصب/دستگاه ذخیره می‌شوند و با سایر گوشی‌ها همگام نیستند.
- برنامه هفتگی و محتوا نمونه هستند.

هشدار مهم:
این پروژه برای نمونه اولیه/ارائه آموزشی است، نه استفاده عمومی امن. رمز در کد جاوااسکریپت قابل مشاهده است و داده‌ها در localStorage دستگاه ذخیره می‌شوند. برای استفاده واقعی مدرسه، بک‌اند و پایگاه داده مرکزی، احراز هویت امن مدیر، مجوزها، پشتیبان‌گیری و سیاست حریم خصوصی لازم است. اطلاعات حساس دانش‌آموزان را در این نسخه وارد نکنید.

فونت:
فونت Vazirmatn در CSS از Google Fonts بارگیری می‌شود؛ اگر اینترنت نباشد، فونت جایگزین دستگاه استفاده می‌شود.
